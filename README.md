# 🏥 FilaSaúde — Gestão de Atendimento

Sistema web desenvolvido como parte da disciplina de **PBL (Problem-Based Learning)**, alinhado ao tema semestral:  
> *"Soluções Digitais como Meio de Transformação de Processos"*

---

## 🎯 Objetivo do Projeto

O **FilaSaúde** visa modernizar e otimizar o fluxo de acolhimento e triagem em unidades de saúde, proporcionando:
- Organização e visibilidade em tempo real das filas de espera.
- Chamada ágil e padronizada de pacientes.
- Registo centralizado do histórico e métricas básicas de tempo de atendimento.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Java 17+
- **Framework:** Spring Boot 3
- **Camada Web/Template:** Spring MVC + Thymeleaf
- **Persistência de Dados:** Spring Data JPA + Hibernate
- **Base de Dados:** PostgreSQL
- **Front-end / Estilo:** Bootstrap 5

---

## 🚀 Como Executar o Projeto Localmente

### Pré-requisitos
- JDK 17 (ou superior) instalado e configurado nas variáveis de ambiente.
- Instância local do PostgreSQL a correr na porta `5432`.
- Git instalado.
